# 🛠️ SQL – Fundamentos e Práticas para DBA Júnior

Repositório criado para estudo e prática de **SQL**, com foco em fundamentos técnicos e rotinas básicas esperadas para uma posição de **DBA Júnior**.

O projeto utiliza um cenário de dados fictícios para aplicar conceitos de criação, organização, manutenção e análise de bancos de dados relacionais, podendo ser utilizado em diferentes SGBDs.

## 🎯 Objetivo

- Consolidar fundamentos de SQL
- Praticar criação e organização de bancos de dados relacionais
- Trabalhar com tabelas, chaves e relacionamentos
- Aplicar boas práticas de estrutura e manutenção
- Exercitar análise de consultas e performance básica
- Praticar rotinas de backup e restore
- Construir portfólio técnico voltado para DBA Júnior

## 🧰 Tecnologias e Bancos de Dados

- SQL padrão ANSI
- MySQL
- PostgreSQL
- SQLite
- SQL Server
- VS Code
- Ferramentas gráficas de administração de banco de dados

## 🧩 Sobre o Projeto

O banco de dados utiliza **diferentes cenários simulados**, permitindo aplicar conceitos técnicos independentes de SGBD, tais como:

- Criação de tabelas e relacionamentos
- Definição adequada de tipos de dados
- Consultas com JOIN e agregações
- Criação de views
- Organização e versionamento de scripts SQL
- Exportação e restauração de dados (backup/dump)

⚠️ Todos os dados utilizados são **fictícios** e foram gerados exclusivamente para fins educacionais.
